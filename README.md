# 柴柴收藏樂園：第五階段

## 頁面

- `index.html`：學習樂園選單首頁，顯示展示柴柴與目前金幣。
- `practice.html`：練習園地選單，使用獨立於首頁的視覺風格，列出可擴充的練習項目。
- `practice-menu.js`：練習選單項目清單；新增練習時可登記標題、類別、說明及頁面連結。
- `collection.html`：收藏圖鑑、收藏彈窗與展示造型選擇。
- `shop.html`：柴柴轉蛋機、轉蛋動畫、結果與最近抽獎紀錄。
- `four-digit-add-subtract.html`：不超過 10,000 的四位數加減法填空練習。
- `three-digit-multiplication.html`：三位數乘以一位數填空練習。
- `practice-exercises.css`：兩個練習頁共用的學習樂園視覺樣式。
- `shop.css`：轉蛋機外觀、動畫、不同稀有度演出與響應式版面。
- `rarity.js`：稀有度分組、機率及抽獎池資料的唯一來源。

抽獎結果以圖鑑卡片覆蓋轉蛋機；按卡片右上角 × 可收起結果。再次抽獎時，結果卡片先收起，再開始轉蛋動畫。商店只顯示最近抽獎紀錄，不另列機率欄。

抽獎先依收藏進度和連續重複次數判定新收藏或重複，再從符合結果的候選角色中按 50:30:15:5 稀有度權重重新正規化抽選。01 原型是贈送角色，不會抽中，也不計入 31 款抽獎收藏進度。新正式存檔從 0 金幣與僅收藏 01 開始。連續重複次數與每筆抽獎結果都會持久化。

## 測試帳本

目前 `app-config.js` 的 `testMode` 預設為 `true`，供開發與驗收使用。應用使用獨立的 `shibaGallery.stage3.test.v1` 帳本；首次建立時給予 100,000 測試金幣，之後重載沿用餘額。商店會顯示「測試模式」與「重設測試帳本」，重置只改測試帳本。正式帳本使用 `shibaGallery.stage3.v1`，測試模式不讀取舊版正式資料。正式發佈前必須切回 `false` 並確認測試功能已在發佈建置中關閉。這是純前端設定，不能作為防作弊措施。

自動化驗收：在專案根目錄執行 `node verify-stage3.cjs`。測試包含固定種子的 50,000 次抽選模擬、機率和候選稀有度分布、遷移、帳本隔離、退款、練習暫存獎勵、完成結算冪等、放棄測驗作廢、跨頁共用與重載恢復。

## 數學練習與金幣

兩個練習頁沿用圖鑑與商店的 Stage 3 帳本。每題首次答對在本次測驗暫得 10 金幣；該題先前答錯後答對暫得 1 金幣。「放棄本題」從本次暫存金額扣 5，最低為 0，不影響資產。完成 50 題後，透過唯一完成交易 ID 一次結算到共用資產。測驗中確認「放棄測驗」會清除進度與所有本次暫存金額；取消確認則繼續作答。離開、關閉或重新載入會保留進度及暫存金額，不視為放棄。每題答錯與放棄分開記錄。

```js
window.SHIBA_GAME.awardCoins(32, '數學練習完成結算', 'math-session-123-completion');
```

共用帳本獎勵需正整數、非空原因和唯一交易 ID；重試相同交易不會重複計入。數學、商店及圖鑑使用同一套正式或測試帳本，其他分頁的餘額變動會同步顯示。

## 儲存與升級

正式遊戲資料儲存在 `shibaGallery.stage3.v1`，包含餘額、收藏、展示造型、抽獎紀錄、連續重複次數、加幣與扣款交易，以及數學練習進度。偵測到舊版 `shibaGallery.stage2.v2` 時會保留非 DEMO 收藏及展示造型；舊版預設的 `[1, 4, 9, 12, 18, 25]` 示範收藏會轉成僅有 01。已存在的金幣與收藏會保留。
